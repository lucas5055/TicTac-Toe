## 🎲 About the Game
**Tic Tac Toe** is a simple but classic logic game played on a 3x3 grid.  
Two players take turns marking **X** and **O** — whoever makes a full line first wins.  
If no one does... it’s a draw 🤝

---

## 🕹️ How to Play

There are currently **two versions** available:
- 🧠 **Single Player (vs AI)**
- 🧍‍♂️🧍‍♀️ **Two Players (Local)**  
> ⚠️ Make sure to check the filenames before downloading!

### Controls:
| Action | Keys |
|:--|:--|
| Move | `W`, `A`, `S`, `D` or Arrow Keys |
| Mark (Player X) | `X` or `Left Ctrl` |
| Mark (Player O) | `O` or `Enter` *(Not the NumPad Enter!)* |

🧍 **Two Player Mode:**  
- Player 1 (left side): controls **X** with `WASD + X/LCtrl`  
- Player 2 (right side): controls **O** with `Arrows + O/Enter`

🤖 **Single Player Mode:**  
- You play as **O** using the same movement keys  
- The AI controls **X**
